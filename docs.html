Membangun Sistem UI Neo-Brutalis dengan CSS Modern Murni

Sebuah arsitektur antarmuka web tanpa dependensi bundler atau framework, memanfaatkan kekuatan asli CSS Custom Properties, layout Grid modular, dan semantik HTML5 tingkat lanjut.

1. Pengantar Vanilla UI

Banyak proyek antarmuka web modern langsung mengimpor ratusan megabyte dependensi (Tailwind, Node packages, CSS-in-JS runtimes) sebelum satu baris CSS pun ditulis. Padahal, platform web saat ini telah memiliki kapabilitas native yang luar biasa: CSS Variables (Design Tokens), CSS Grid, fungsi matematis seperti clamp(), dan native dialog API.

Gaya visual Neo Brutalism di sini dieksekusi dengan pendekatan nyaman dipandang (muted warm): bukan kontras norak dengan warna neon menyilaukan, melainkan border solid gelap berpadu dengan permukaan krem hangat, bayangan tegas tanpa blur, serta ketukan taktil yang memuaskan saat disentuh.

Filosofi Zero-Build
File HTML dan CSS dalam panduan ini dapat dibuka langsung di peramban tanpa perintah npm install atau npm run build. Hal ini menjamin longevity (daya tahan) kode hingga 10–20 tahun ke depan.

2. Struktur Design Tokens

Setiap keputusan warna, spasi, dan bayangan diatur terpusat di dalam file tokens.css menggunakan custom properties pada pseudo-class :root. Ini memudahkan pergantian tema warna secara instan tanpa mengacaukan struktur selector komponen.

CSS — tokens.css 
:root {
  /* Latar dan Permukaan Muted */
  --bg:          #F4EFE6; /* Krem hangat, bukan putih murni */
  --surface:     #FDFBF7; /* Permukaan kartu */
  --ink:         #26252C; /* Teks & border solid, bukan #000 pekat */
  --ink-soft:    #595764; /* Teks sekunder yang lembut */

  /* Palet Aksen Pastel Berkarakter */
  --accent-peach:   #EBB6A4;
  --accent-sage:    #B8CBA8;
  --accent-blue:    #A7BCD8;
  --accent-mustard: #EAD287;

  /* Hard Shadows Khas Neo Brutalism */
  --border:    2.5px solid var(--ink);
  --shadow-sm: 2px 2px 0 var(--ink);
  --shadow:    4px 4px 0 var(--ink);
}

3. Palet Neo Brutalism Muted

Kesalahan umum pembuat web neo brutalism adalah menggunakan warna neon hiper-jenuh seperti #00FF00 atau #FF00FF yang menyebabkan kelelahan mata (eye fatigue). Kami meredam saturasi tersebut ke rentang 30%–50% dengan tone pastel yang matang.

Perhatian Kontras WCAG
Jangan gunakan warna aksen cerah seperti kuning mustard sebagai latar belakang teks putih! Selalu pasangkan latar mustard atau peach dengan teks gelap #1B1A22 untuk menjaga rasio kontras di atas 4.5:1.

4. Interaksi Taktil & Tombol

Neo brutalism terasa hidup karena fisika interaksi yang dapat dirasakan. Saat pengguna menekan sebuah tombol, elemen tersebut secara fisik bergerak diagonal sejauh 2 piksel dan bayangannya mengecil secara proporsional.

CSS — components.css 
.btn {
  border: var(--border);
  box-shadow: var(--shadow);
  transform: translate(0, 0);
  transition: transform 140ms ease, box-shadow 140ms ease;
}

.btn:hover {
  transform: translate(-2px, -2px);
  box-shadow: 6px 6px 0 var(--border-color);
}

.btn:active {
  /* Efek tertekan ke dalam */
  transform: translate(2px, 2px);
  box-shadow: 1px 1px 0 var(--border-color);
}

5. Tipografi Fluid dengan clamp()

Alih-alih menulis puluhan media query untuk setiap ukuran heading, kami memanfaatkan fungsi bawaan CSS clamp(min, preferred, max). Teks secara otomatis membesar dan mengecil secara proporsional dari layar smartphone 360px hingga monitor desktop 1440px.

CSS — tokens.css 
:root {
  /* Responsif dari 28px di mobile hingga 50px di monitor lebar */
  --text-3xl: clamp(1.75rem, 1.4rem + 1.8vw, 3.125rem);
  --text-2xl: clamp(1.4rem, 1.2rem + 1.2vw, 2.25rem);
  --text-base: clamp(0.9375rem, 0.9rem + 0.35vw, 1.0625rem);
}

6. Dark Mode Tanpa FOUC

Untuk mencegah kedipan layar putih saat halaman dimuat (Flash of Unstyled Content / FOUC), script pembaca preferensi tema dieksekusi sedini mungkin dan disimpan ke dalam localStorage.

Tips Performa
Di dalam file js/main.js, fungsi applyTheme() dipanggil sebelum event DOMContentLoaded selesai agar token CSS gelap segera aktif saat dokumen HTML pertama kali diparse oleh mesin peramban.

7. Aksesibilitas & Navigasi Keyboard

Setiap elemen interaktif (tombol, link, tab ulasan) memiliki :focus-visible ring tebal berwarna kuning mustard dengan outline offset 3px. Pengguna disabilitas motorik dapat bernavigasi menggunakan tombol Tab dengan rasa percaya diri penuh tanpa kehilangan fokus visual.

8. Pembersihan AI Slop

Website yang dirancang dengan selera manusia menghindari klise template AI seperti latar belakang seragam kartu persegi melengkung, gradien ungu neon generik, dan emoji sebagai pengganti ikon UI resmi. Setiap ikon pada arsitektur ini menggunakan format SVG inline yang tajam dan dapat diubah warnanya secara dinamis melalui atribut currentColor.
